# Portfolio and Watchlist

Portfolio and watchlist tools help you separate stocks you own from stocks you are only monitoring.

Use **Portfolio** for holdings you own or seriously model as holdings. Use **Watchlist** for ideas you want to research later.

## Portfolio vs Watchlist

| Area | Use it for |
| --- | --- |
| Portfolio | Holdings, quantities, purchase prices, allocation, performance, and portfolio-level analysis. |
| Watchlist | Stocks you want to monitor before deciding whether they belong in a portfolio. |

This separation matters. A stock can look interesting in research but still be wrong for your portfolio because of concentration, risk, or time horizon.

## My Portfolios

Use My Portfolios to create and manage portfolio views.

You may use portfolios to:

- Track holdings.
- Review allocation.
- See performance context.
- Compare stock-level research with portfolio-level exposure.
- Revisit saved portfolio reports.

## Creating a Useful Portfolio

A useful portfolio starts with clean holdings. Before relying on portfolio analysis, make sure each holding is accurate.

Important fields usually include:

| Field | Why it matters |
| --- | --- |
| Stock name or symbol | Connects the holding to the correct listed stock. |
| Quantity | Determines position size and total value. |
| Purchase price | Helps calculate gain or loss. |
| Purchase date | Helps you understand holding period and report context. |
| Notes | Optional context such as strategy, reason for purchase, or follow-up action. |

Use simple portfolio names such as `Long Term`, `Trading`, `Family`, or `Learning Watch` so you can recognize the purpose later.

## Upload Portfolio

Portfolio upload is useful when you already have holdings in a file.

Before uploading:

- Use the file format shown in the app.
- Check stock symbols and company names.
- Confirm quantities and purchase prices.
- Remove blank rows or merged cells if the upload fails.
- Start with a smaller file if a large upload has problems.

After uploading, review the imported holdings before relying on portfolio results.

### Upload Checklist

Before trying again after a failed upload:

1. Remove extra title rows above the table.
2. Make sure each holding is on its own row.
3. Keep one symbol or stock name per row.
4. Use plain numbers for quantity and price.
5. Use a consistent date format.
6. Remove merged cells.
7. Save a copy of the original file before editing it.

If the app shows a sample format, match that sample first. It is better to upload a clean small file than a complex file with hidden formatting.

## Portfolio Analysis

Portfolio analysis helps you review the group of holdings together instead of one stock at a time.

It may help answer:

- Am I too concentrated in one stock or sector?
- Which holdings are helping or hurting performance?
- Does my portfolio depend too much on one theme?
- Are risk notes different when stocks are viewed together?
- Has a saved report become stale because holdings changed?

### What Portfolio Analysis Helps You Notice

| Area | What it means |
| --- | --- |
| Stock concentration | One holding may be too large compared with the rest. |
| Sector concentration | Too many holdings may depend on the same industry. |
| Portfolio risk | The group may move sharply even if individual stocks look acceptable. |
| Overlap | Multiple stocks may react to the same market event. |
| Weak holding | A stock may look weaker than the rest of the portfolio. |
| Strong contributor | A stock may be driving most of the gain. |

Portfolio analysis is different from stock analysis. A good stock can still make a portfolio riskier if you already own similar stocks.

## Saved Portfolio Reports

Saved reports and fresh report generation are different.

You may be able to read a saved report even when a new report is not currently available for your account. If the portfolio changed after the saved report was created, generate a fresh report when available before relying on it.

Check saved reports for:

- Report date.
- Portfolio name.
- Holdings at the time of the report.
- Any warning, locked, or limit message.
- Whether the report still matches your current holdings.

## Watchlists

Use watchlists to monitor ideas without treating them as owned positions.

Good watchlist uses:

- Track stocks you want to research.
- Keep sector ideas separate.
- Monitor chart setups or news-driven names.
- Review stocks before adding them to a portfolio.

Avoid using a watchlist as a replacement for a portfolio. It does not show real allocation or position size.

### Good Watchlist Categories

You can organize watchlists by:

- Sector ideas.
- Long-term candidates.
- Short-term chart setups.
- News-driven stocks.
- Stocks to research later.
- Stocks you already own but want to monitor separately.

Keep watchlists focused. A very large watchlist becomes hard to review.

## How to Review a Portfolio

1. Confirm holdings are up to date.
2. Review total value and allocation.
3. Check concentration by stock and sector.
4. Open stock-level reports for the largest or riskiest holdings.
5. Review portfolio analysis when available.
6. Compare saved report date with current holdings.
7. Decide what needs follow-up, not just what looks positive.

## Common Problems

| Problem | What to check |
| --- | --- |
| Portfolio value looks wrong | Quantity, purchase price, stock symbol, and whether prices have updated. |
| Upload failed | File type, required columns, blank rows, symbols, and date format. |
| A stock is missing | Confirm it was added to the correct portfolio or watchlist. |
| Report looks old | Check report date and whether holdings changed later. |
| Tool looks locked | Check the message shown in the app and the live pricing page. |

## Portfolio Terms

| Term | Meaning |
| --- | --- |
| Holding | A stock position in your portfolio. |
| Allocation | How much of your portfolio belongs to a stock or sector. |
| Gain or loss | Difference between current value and purchase value. |
| Unrealized gain or loss | Gain or loss on a holding you still own. |
| Realized gain or loss | Gain or loss after a holding is sold. |
| Diversification | Spreading exposure across stocks or sectors. |
| Concentration | Too much exposure to one stock, sector, or theme. |
| Rebalance | Adjusting holdings so the portfolio better matches your intended structure. |

## Best Practices

- Keep holdings accurate before running portfolio analysis.
- Use watchlists for ideas, not ownership.
- Review concentration before adding another stock from the same sector.
- Do not rely on an old portfolio report after changing holdings.
- Use stock reports and portfolio reports together.
- Keep notes on why a stock is in a portfolio or watchlist.
- Review large holdings more often than small research ideas.
- Treat upload results as something to verify, not something to trust blindly.
