# Chart Pattern Analysis

Chart Pattern Analysis focuses on price structure. It detects chart setups, ranks them by confidence, and explains the strongest pattern.

## What It Helps You Answer

- Is there a recognizable chart setup?
- Is the pattern bullish, bearish, or neutral?
- How confident is the setup?
- What level matters most?
- What invalidates the setup?
- Are there secondary patterns worth noting?

## Important Disclaimer

Pattern detection is probabilistic. Corporate actions, thin liquidity, abrupt news, and fast market movement can invalidate a setup quickly. Use chart patterns as research support, not standalone trading signals.

## Pattern Terms Explained

| Term | Meaning |
| --- | --- |
| Bullish | The pattern leans positive if it confirms. |
| Bearish | The pattern leans negative if it confirms. |
| Neutral | The pattern does not strongly favor either direction. |
| Breakout | Price moves beyond a key resistance or pattern boundary. |
| Support | A price area where buying interest may appear. |
| Resistance | A price area where selling pressure may appear. |
| Target | A possible price objective if the setup works. |
| Invalidation | A level or condition that weakens the setup. |
| Secondary pattern | Another detected setup that did not receive the main AI explanation. |

## How To Use The Pattern Feed

The pattern feed is useful for discovery, but it should not be read as a trade list.

Use it like this:

1. Review the highest-confidence setups.
2. Open the full report only for stocks you care about.
3. Check whether the pattern is bullish, bearish, or neutral.
4. Read the invalidation context before the target context.
5. Compare with Traditional Analysis, Smart AI Analysis, and AI News.

If a preview hides details, use the preview to understand the type of setup, then check plan access if you need full detail.

## How To Read Key Levels

Key levels are not promises. They are reference points for risk and structure.

Example:

- If the report shows a bullish pattern with support near a level, price falling below that level may weaken the setup.
- If the report shows a target, that target is a reference, not a guarantee.
- If the invalidation level is close to current price, the setup may be fragile.

## How Chart Patterns Fit With Other Reports

Chart Pattern Analysis is strongest when used with:

- Traditional Analysis for company quality and valuation.
- Advanced AI Analysis for AI-assisted forecast context.
- Smart AI Analysis for blended interpretation.
- AI News for recent catalysts.

A bullish chart setup on a weak company should be treated differently from a bullish setup on a fundamentally strong company.

## Common Mistakes

- Treating the target level as a guaranteed price.
- Ignoring invalidation.
- Assuming a high-confidence pattern removes market risk.
- Using a chart pattern without checking news.
- Trusting an old pattern after price has already moved.
- Confusing a detected setup with personal trading advice.
