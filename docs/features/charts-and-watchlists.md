# Charts and Watchlists

Charts and watchlists help you monitor stocks between full analysis runs.

## Charts

Charts are for visual price review. Use them to check:

- Trend direction.
- Recent volatility.
- Support and resistance areas.
- Breakout or breakdown behavior.
- Whether a chart-pattern report visually makes sense.

Charts are not a complete analysis by themselves. Combine chart context with Traditional Analysis, AI reports, and news.

## Reading A Chart Like A User

Start with simple questions:

1. Is the stock trending up, down, or sideways?
2. Is volatility calm or wide?
3. Is price near support, resistance, or a breakout area?
4. Did volume increase near an important move?
5. Does the chart confirm or contradict the latest report?

If you cannot answer those questions, avoid over-interpreting advanced indicators.

## What Charts Are Good For

| Use case | Why it helps |
| --- | --- |
| Checking trend | Helps you avoid reading a report without price context. |
| Reviewing volatility | Helps you understand whether the stock moves smoothly or sharply. |
| Confirming chart-pattern reports | Lets you visually inspect the detected setup. |
| Planning monitoring | Helps decide where alerts or watchlist review may be useful. |
| Comparing report age | Helps identify when an old report may no longer match current price action. |

## Watchlists

A watchlist is for stocks you want to monitor. It is not the same as a portfolio.

| Watchlist | Portfolio |
| --- | --- |
| Stocks you are tracking. | Stocks you own or model as holdings. |
| Good for ideas and alerts. | Good for allocation and performance. |
| Does not represent exposure. | Represents exposure and concentration. |
| Useful before analysis. | Useful for portfolio reports. |

## Practical Workflow

1. Add interesting stocks to a watchlist.
2. Review charts periodically.
3. Run deeper analysis only on names worth studying.
4. Move stocks into a portfolio only when they represent holdings.

## Watchlist Workflows

### Research Watchlist

Use this for stocks you are studying but do not own.

Good examples:

- Stocks mentioned in reports.
- Sector names you are comparing.
- Breakout candidates.
- Long-term ideas you want to watch.

### Follow-Up Watchlist

Use this for stocks that need another check later.

Good examples:

- Smart AI result is split.
- News is mixed.
- A chart pattern is forming but not confirmed.
- Valuation is attractive but risk is high.

### Portfolio Watchlist

Use this only if you want a separate monitoring list for owned names. Do not confuse it with your actual portfolio, because portfolio reports depend on holdings, quantity, and cost data.

## Chart Terms

| Term | Meaning |
| --- | --- |
| Timeframe | The period shown on the chart, such as daily or longer ranges. |
| Candlestick | A chart style showing open, high, low, and close for each period. |
| Trend | General direction of price movement. |
| Support | Area where price has previously found buying interest. |
| Resistance | Area where price has previously faced selling pressure. |
| Breakout | Price moving beyond a prior resistance or pattern boundary. |
| Breakdown | Price moving below an important support or pattern boundary. |
| Volume | Number of shares traded during a period. |
| Gap | A jump between one period's close and the next period's open. |

## Watchlist Best Practices

- Keep separate watchlists for different themes if needed.
- Remove stocks you are no longer researching.
- Do not confuse watchlist count with portfolio diversification.
- Re-run analysis only when something has changed or the stock becomes relevant.

## Common Mistakes

- Treating a watchlist as proof of diversification.
- Keeping too many symbols and never reviewing them.
- Ignoring old report dates after price has moved.
- Treating chart levels as guaranteed outcomes.
- Moving a stock into a portfolio without entering accurate holding details.
