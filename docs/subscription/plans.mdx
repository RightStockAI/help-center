# Plans and Access

RightStockAI plans decide which tools you can use fully and how often you can create new research.

This page is not a pricing table. It explains the words and messages you may see while using the app, so you can understand whether you are seeing a preview, a plan limit, a cooldown, or a saved report.

For current prices, offers, and included limits, always use the live pricing page:

[View current RightStockAI pricing](https://www.rightstockai.com/pricing)

## What Your Plan Can Affect

Your plan can affect four common parts of the product.

| Area | What it means for you |
| --- | --- |
| Tools you can open | Some tools may be fully available, preview-only, or locked. |
| New analysis limits | Some plans limit how many fresh reports you can generate. |
| Waiting time | Some tools may ask you to wait before running another analysis. |
| Saved report access | You may still be able to view an older saved report even when a new run is not available. |

These are different things. For example, you might be able to read a saved portfolio report but still need to wait before generating a new one.

## Messages You May See

| Message or state | What it usually means |
| --- | --- |
| Full access | Your current plan can open the complete tool or report. |
| Preview | You can see part of the feature, but some details are hidden. |
| Locked | Your current plan does not include full access to that tool. |
| Limit reached | You used the available new runs for that tool. |
| Cooldown active | You need to wait before generating another report. |
| Saved report available | An older report is still available to read. |

If a page looks limited, first check the message shown on the page. It usually tells you whether the issue is plan access, usage, cooldown, or a saved report.

## Preview vs Locked

Preview and locked pages are not the same.

**Preview** means the app lets you see a limited sample so you can understand the feature before upgrading. A preview may hide stock names, chart levels, full report details, or the complete list.

**Locked** means your current plan does not include that tool or report. The page may show an upgrade button or a link to pricing.

## New Reports vs Saved Reports

A **new report** is generated when you ask RightStockAI to run fresh analysis.

A **saved report** is an older report that was already generated and stored for later viewing.

This difference matters because a plan limit may block a new analysis while still letting you read an older saved report.

Example:

1. You open a portfolio report that was generated earlier.
2. The report is visible.
3. You click rerun.
4. The app asks you to wait or upgrade.

That usually means saved report viewing is available, but a fresh report is limited.

## Cooldowns and Usage Limits

Some tools limit how often you can create new analysis.

A **usage limit** answers: how many new reports can I generate?

A **cooldown** answers: how long must I wait before running this again?

If you expected a limit to reset but the tool is still unavailable, check whether a cooldown is still active.

## Before You Upgrade

Before choosing a plan, ask:

1. Which feature am I trying to unlock?
2. Do I need to create new reports often, or mostly read saved reports?
3. Am I using stock analysis, chart patterns, Smart AI Picks, portfolio tools, or all of them?
4. Did the page say preview, locked, limit reached, or cooldown?
5. Have I checked the current pricing page?

Then compare the live plans:

[Compare current plans](https://www.rightstockai.com/pricing)

## After You Upgrade

If you upgraded but a tool still looks locked:

1. Refresh the page.
2. Sign out and sign in again.
3. Open **My Subscription** to confirm your current plan.
4. Check whether the tool has a waiting time before the next run.
5. Contact support if the issue continues.

When contacting support, include your account email and the name of the tool that still looks locked.

## Payment Safety
