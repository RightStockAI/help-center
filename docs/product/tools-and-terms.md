# Tools and Terms

This page explains the words users see inside RightStockAI.

## Product Tools

| Tool | Meaning |
| --- | --- |
| Basic AI Analysis | A fast AI-assisted stock read for quick direction. Use it before deciding whether deeper analysis is needed. |
| Traditional Analysis | A stock report using fundamentals, technical indicators, valuation context, analyst context, risk metrics, and a recommendation view. |
| Advanced AI Analysis | A deeper AI-assisted stock report with forecast context, confidence, target/risk framing, and supporting reasons. |
| Smart AI Analysis | A blended report combining Traditional, AI Predictive, and Sentiment inputs into one Smart AI verdict. |
| Chart Pattern Analysis | A detector that finds chart setups, ranks patterns by confidence, explains the top pattern, and shows key levels. |
| AI News Analysis | A stock-news research tool that summarizes sentiment, catalysts, and risk context. |
| Stock Research Reports | A report-browsing area for recent shared research and saved analysis access. |
| Smart AI Picks | A premium shortlist where chart pattern, Smart analysis, and final AI verdict align. |
| Portfolio Management | Holdings tracking, portfolio upload, allocation view, and portfolio-level reports. |
| Watchlist | A monitoring list for stocks you want to study without marking them as owned holdings. |
| Charts | Price and technical chart views for symbol-level review. |

## Report Terms

| Term | Meaning |
| --- | --- |
| Recommendation | A report's label such as Strong Buy, Buy, Hold, Sell, or Strong Sell. It is a research label, not personal advice. |
| Confidence | A measure of signal strength or agreement. High confidence still carries risk. |
| Overall score | A normalized score used by some reports to summarize multiple inputs. |
| Target price | A price reference used for upside/downside context. It can become stale. |
| Current price | The price captured or shown by the report context. |
| Upside potential | The difference between current price and target/predicted price, usually shown as a percentage. |
| Risk level | A report's simplified risk label, often based on volatility, drawdown, or signal conflict. |
| Supporting reasons | The evidence behind a recommendation, such as RSI, analyst context, confidence, volatility, or drawdown. |
| Invalidation level | In chart pattern reports, a level that weakens or invalidates the setup if breached. |
| Key levels | Support, resistance, target, breakout, or invalidation prices shown in chart-pattern reports. |
| Saved report | A report already generated and stored. |
| Fresh run | A new report generation request. Plan limits usually apply to fresh runs. |

## How To Read Any Report

Most RightStockAI reports can be read with the same simple order.

1. Confirm the stock name and symbol.
2. Read the recommendation or verdict.
3. Check confidence or score.
4. Read supporting reasons.
5. Read caution points.
6. Check report date or freshness.
7. Compare another tool if the decision matters.
8. Check portfolio exposure if you own the stock.

This order prevents a common mistake: seeing a positive label and skipping the risk section.

## Recommendation Labels

Recommendation labels are shorthand. They summarize the report's view, but they do not replace the explanation.

| Label style | How to read it |
| --- | --- |
| Strong Buy or Buy | The report is positive, but risks and valuation still matter. |
| Hold or Neutral | The report may be balanced, uncertain, or waiting for stronger evidence. |
| Sell or Cautious | The report is warning about weakness, risk, or poor signal quality. |
| Bullish or Bearish | Directional view, often used in chart or AI context. |
| Mixed or Split | Inputs disagree. Read the conflict before deciding what to do next. |

## Access Terms

| Term | Meaning |
| --- | --- |
| Free plan | A no-cost plan for light usage, basic product learning, and selected previews. |
| Trial | Temporary upgraded access when a trial is available in the live app. Check live Pricing for current duration and scope. |
| Pro | Paid plan for regular research users who need fuller access than Free. |
| Premium | Paid plan for heavier research workflows and the highest access currently shown in the app. |

| Cooldown | A waiting period before the next fresh run is allowed. |
| Upgrade prompt | A message explaining what plan unlocks the feature. |

Live prices and included plan limits are intentionally not copied into this dictionary. Use [RightStockAI Pricing](https://www.rightstockai.com/pricing) for current plan details.

## Access Messages You May See

| Message style | What it usually means |
| --- | --- |
| Preview | You can see limited information, but some details may be hidden. |
| Locked | Your current plan may not include the full feature. |
| Limit reached | You may have used the available fresh runs for that feature. |
| Cooldown | The app is asking you to wait before generating another fresh report. |
| Saved report | You are reading a previously generated report, not a new run. |

If an access message is unclear, check [Plans and Access](../subscription/plans) before contacting support.

## Indicator Terms

| Indicator | Meaning |
| --- | --- |
| RSI | Relative Strength Index. Often used to identify overbought or oversold momentum conditions. |
| MACD | Moving Average Convergence Divergence. A momentum and trend indicator. |
| Moving average | A smoothed average of price used to understand trend direction. |
| Sharpe ratio | A risk-adjusted return measure. Higher is generally better, but context matters. |
| Altman Z-Score | A financial distress indicator used in fundamental analysis. |
| Piotroski F-Score | A quality score for company fundamentals. |
| Beneish M-Score | A model used to flag potential earnings manipulation risk. |

## Chart Pattern Terms

| Term | Meaning |
| --- | --- |
| Pattern | A recognizable price structure on the chart. |
| Breakout | Price moves above an important area or pattern boundary. |
| Breakdown | Price moves below an important support or pattern boundary. |
| Support | A price area where buyers may appear. |
| Resistance | A price area where sellers may appear. |
| Target | A reference level if the setup works. It is not a promise. |
| Invalidation | A level or condition that weakens the setup. |

## Best Practice

Do not rely on one label. Read the recommendation, confidence, supporting reasons, risk notes, and report age together.
