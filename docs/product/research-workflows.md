# Research Workflows

RightStockAI is easiest to use when you follow a workflow instead of opening tools randomly.

## Beginner Workflow

Use this when you are learning the product:

1. Open Markets to understand the broad day.
2. Choose one familiar stock.
3. Open Traditional Analysis.
4. Read recommendation, confidence, risk, and supporting factors.
5. Open Advanced AI Analysis for comparison.
6. Add the stock to a watchlist if you want to monitor it.

Goal: learn how reports are structured before using premium idea feeds.

## Deep Stock Research Workflow

Use this when you are seriously evaluating one stock:

1. Open the stock detail page.
2. Review the chart.
3. Run Traditional Analysis.
4. Run Advanced AI Analysis.
5. Run Smart AI Analysis.
6. Run Chart Pattern Analysis.
7. Read AI News.
8. Compare conflicts between methods.
9. Save or revisit reports later.

Goal: understand fundamentals, AI view, sentiment, chart structure, and risk.

## Portfolio Review Workflow

Use this when you already own stocks:

1. Upload or maintain holdings.
2. Review portfolio allocation.
3. Check concentration by stock and sector.
4. Run Traditional Portfolio Analysis when available.
5. Run AI Portfolio Analysis when included in your plan.
6. Revisit saved portfolio reports before starting a new run.

Goal: understand exposure, not just individual stock opinions.

## Watchlist Workflow

Use this when you are building a shortlist:

1. Add stocks to a watchlist.
2. Use charts to monitor structure.
3. Run analysis only on names worth deeper research.
4. Move stocks from watchlist to portfolio only when they represent real holdings.

Goal: separate "interested" from "owned".

## Premium Research Workflow

Use this when you have full research access:

1. Review Stock Research Reports for recent shared ideas.
2. Review Smart AI Picks for higher-signal overlap.
3. Open the symbol detail page for any idea you care about.
4. Run Smart AI or Chart Pattern Analysis for current context.
5. Check whether the report is saved or freshly generated.

Goal: use curated surfaces as discovery, not as automatic decisions.

## Choosing The Right Tool

| Need | Best starting point |
| --- | --- |
| Understand the market day | Markets |
| Quick first read on one stock | Basic AI Analysis |
| Finance-first company view | Traditional Analysis |
| Deeper AI-supported view | Advanced AI Analysis |
| Combined Traditional, AI, and Sentiment view | Smart AI Analysis |
| News catalyst and sentiment check | AI News Analysis |
| Chart setup and key levels | Chart Pattern Analysis |
| Browse recent research ideas | Stock Research Reports |
| Curated premium shortlist | Smart AI Picks |
| Monitor ideas | Watchlist |
| Analyze owned holdings | Portfolio Analysis |

## Evidence Ladder

For important decisions, build evidence step by step:

1. Market context.
2. Stock chart.
3. Traditional Analysis.
4. Advanced AI Analysis.
5. Smart AI Analysis.
6. AI News.
7. Chart Pattern Analysis.
8. Portfolio exposure.
9. Report freshness.

The goal is not to make every signal agree. The goal is to understand where they agree, where they conflict, and what risk remains.

## Conflict Handling Workflow

Use this when reports disagree:

1. Identify which tool is positive and which is cautious.
2. Check whether the conflict is about valuation, trend, news, sentiment, or risk.
3. Check report dates.
4. Re-run only the report that is stale or most relevant.
5. Read caution points before supporting points.
6. Avoid forcing a conclusion if the evidence is mixed.

Examples:

- Smart AI is positive but news is negative: review AI News and recent catalysts.
- Chart pattern is bullish but Traditional Analysis is weak: check fundamentals and risk.
- Traditional Analysis is positive but AI is cautious: inspect forecast confidence and report age.
- A saved portfolio report looks good but holdings changed: update the portfolio and generate a fresh report when allowed.

## When To Stop And Recheck

Pause before acting when:

- Confidence is low.
- The recommendation and risk notes conflict.
- The chart pattern is bullish but fundamentals are weak.
- The AI view is positive but recent news is negative.
- A saved report is old.
- Your plan is showing a teaser instead of full details.
